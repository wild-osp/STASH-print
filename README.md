# 🖨️ STASH Print — Быстрая отправка файлов на печать

Простая и адаптивная веб-страница для клиентов сервисного центра **STASH**. Позволяет мгновенно передавать документы и фотографии на печать со смартфона через привычные мессенджеры или электронную почту в один клик.

🔗 **Демо / Сайт:** [https://wild-osp.github.io/STASH-print/](https://wild-osp.github.io/STASH-print/)

---

## 🚀 Основные возможности

- **Выбор и управление файлами:**
  - Мультизагрузка файлов прямо с телефона (`.pdf`, `.docx`, `.jpg`, `.png` и др.).
  - Интерактивный список выбранных файлов с отображением размера.
  - Возможность удалить ошибочно выбранный файл по кнопке ✕ перед отправкой.
- **Быстрый переход в мессенджеры в один клик:**
  - 💬 **Viber** (прямой переход в чат по номеру `+375 (29) 150-77-74`).
  - ✈️ **Telegram** (прямая ссылка на профиль `@Stashop_osp`).
  - 🟢 **WhatsApp** (открытие диалога через официальный `wa.me`).
  - 📧 **Email** (`info@stash.by` с автоматическим заполнением темы и списка прикрепляемых файлов).
- **Современный мобильный дизайн:**
  - Адаптирован под экраны любых смартфонов (iOS и Android).
  - Крупные контрастные кнопки с официальными векторными логотипами (SVG).
  - Понятный интерфейс для клиентов любого возраста без регистраций и паролей.
- **Готовый макет для стойки (QR-код):**
  - Возможность распечатать настольную табличку (форматы A4 и A5) с большим QR-кодом для быстрого сканирования камерой.
